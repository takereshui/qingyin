# 轻音

> 让音乐回到音乐本身。

**轻音**是一款面向 Android 的本地与在线音乐播放器。它把本地曲库、歌单、歌词、播放队列和下载管理放进一条简洁的使用路径：打开应用，找到音乐，开始播放。

## 1.0.35 更新

修复本地歌单在应用重启后可能出现的连续播放失败与异常跳歌。此前本地歌单只保存曲目 ID，没有保存系统媒体库或自选目录的真实文件地址；重新打开歌单后，部分本地条目会被当作无地址的待解析网络项，进而引发错误和连续切歌。

轻音现在会持久化本地与下载曲目的真实 URI，并会在打开旧歌单时按稳定曲目 ID 自动恢复历史缓存中的地址。找不到文件、文件被移动，或已撤销目录授权的条目不会再注入播放器；应用会保留其余曲目的原歌单顺序，并明确告知跳过数量。

下载任务仍会根据真实文件头确认容器格式；标签或封面写入异常只显示完成说明，绝不会阻断已下载音频。

## 主要功能

| 场景 | 轻音提供的体验 |
| --- | --- |
| 本地音乐 | 扫描系统媒体库与用户手动选择的目录；保留本地音频的标题、歌手、专辑、时长与内嵌封面。 |
| 在线播放 | 可搜索网易云与 QQ 音乐的公开曲目，支持在线试听、播放队列与歌词。 |
| 歌单 | 支持同步网易云歌单、导入网易云或 QQ 音乐歌单，以及新建本地歌单；在线单曲可收藏进指定本地歌单。 |
| 下载 | 内置下载队列，显示进度与状态，可删除记录；下载文件尽可能保留原始歌曲元数据与内嵌封面。 |
| 播放体验 | 支持上一首、下一首、顺序/循环/随机播放、进度拖动与后台播放。 |
| 首页 | 本地音乐、播放队列、每日推荐和可自选的首页歌单集中呈现。 |
| 界面 | 酒红、莓紫与雾粉主题；播放页使用当前封面的沉浸式模糊背景与歌词玻璃面板。 |

## 安装

请从本仓库的 [Releases](https://github.com/takereshui/qingyin/releases) 页面下载最新的 `APK` 并安装。Android 首次安装来自浏览器或文件管理器的 APK 时，系统可能要求授予“允许安装未知应用”的权限。

安装后，可以先将轻音作为纯本地播放器使用：在“本地音乐”页面授予音乐访问权限并执行扫描。如果音乐存放在系统媒体库之外，也可以手动选择需要扫描的文件夹。

## 在线服务说明

在线搜索、歌单同步、歌词、试听和下载功能会在用户主动操作时连接相应服务。网易云音乐的数据服务用于搜索、歌单和歌词等信息；网易云与 QQ 的播放、下载音源均由应用设置的 ChKSz 服务处理。实际的音乐可用性、音质选项与访问权限仍取决于内容平台、账号状态、网络状况和服务端状态。

轻音不绕过第三方平台的付费、地区或账号权限限制。使用在线功能前，请遵守所在地法律法规、版权要求及相关服务条款。

## 隐私

本地音乐的扫描、播放和本地歌单不要求登录第三方账号。只有当用户主动使用在线搜索、同步歌单、获取歌词、在线播放或下载时，应用才会请求相应网络服务。
