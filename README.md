# 轻音

**轻音**是一款面向 Android 的无广告音乐播放器，强调**本地优先、界面简洁、播放稳定和不被打扰的听歌体验**。它既可以管理手机中的本地音乐，也支持在线搜索、在线播放、歌单管理和音乐下载，适合希望把常用音乐集中到一个轻量播放器中的用户。

当前发布版本为 **1.0.21**，应用包名为 `im.molan.music`。

## 产品特点

轻音不追求复杂的社交功能和信息流堆叠，而是把重点放在“找到音乐、开始播放、持续聆听”这条主路径上。应用采用无广告设计，首页保留每日推荐与搜索入口，播放页提供清晰的曲目信息和常用控制，让用户能够快速进入播放状态。

| 特点 | 说明 |
|---|---|
| 本地优先 | 自动发现设备中的音乐文件，并支持从系统文件选择器添加音乐目录。 |
| 在线随听 | 支持在线搜索歌曲、歌手和相关音乐资源，获取可播放地址后直接播放。 |
| 稳定播放 | 支持后台播放、锁屏控制、通知栏控制、蓝牙媒体按键和耳机拔出响应。 |
| 无广告体验 | 不在播放流程中插入广告，不以广告信息干扰音乐播放。 |
| 歌单集中管理 | 支持线上歌单同步、本地歌单创建、曲目添加与歌单内播放。 |
| 下载到本地 | 通过应用内下载队列保存音乐，下载完成后可在本地音乐中继续管理。 |

## 核心功能

### 本地音乐管理

轻音会扫描设备中可访问的音频文件，并按照歌曲、歌手、专辑等信息整理本地音乐。用户也可以通过系统文件选择器指定音乐目录，适合管理存放在不同文件夹或外部存储中的音乐。

应用支持本地音乐的连续播放、队列播放、收藏和播放进度记录。封面与歌词等信息会尽量进行本地匹配和缓存，在网络不稳定时仍能保持基本的本地播放体验。

### 在线搜索与在线播放

在搜索页输入歌曲名、歌手名或关键词，即可查找在线音乐。搜索结果可以直接加入播放队列或开始播放；对于已经解析出播放地址的曲目，轻音会在播放时使用在线音源，并在必要时进行地址回退处理。

轻音支持网易云音乐相关的搜索、播放地址获取、歌词和歌单能力。在线服务的可用范围会受到第三方接口、账号状态、地区限制和服务变更影响，具体结果以实际运行情况为准。

### 每日推荐

首页提供每日推荐入口，帮助用户快速发现适合当天聆听的音乐。推荐内容可直接播放，也可以加入当前队列或保存到歌单中。

### 播放队列与后台播放

轻音使用统一播放队列管理当前曲目，支持单曲播放、连续播放、循环播放和随机播放等常用模式。离开应用后，音乐仍可在后台继续播放；用户可以通过锁屏界面、通知栏、蓝牙耳机或车载媒体控制进行播放、暂停、切歌和查看曲目信息。

播放过程中会保留当前播放位置和队列状态，便于在返回应用后继续聆听。对于尚未解析完成的在线曲目，应用会在实际播放到该曲目时继续处理，避免影响歌单整体加载。

### 歌词与封面

轻音会为在线音乐匹配歌词和封面，并将已经获取的信息进行本地缓存。播放页提供歌词查看入口；如果某首歌曲没有可用歌词、封面或在线元数据，应用仍会保留基本播放功能，不会因为附加信息缺失而阻止播放。

### 歌单

歌单页同时提供线上歌单与本地歌单：

- 登录网易云音乐后，可以同步显示与管理账号可访问的歌单。
- 用户可以导入 QQ 音乐或网易云音乐歌单链接、歌单 ID 等信息。
- 用户可以创建本地歌单，并将本地音乐或在线搜索结果加入其中。
- 歌单中的曲目可以直接开始播放，也可以加入当前播放队列。

### 下载管理

轻音提供内置下载队列，用于将可下载的在线音乐保存到应用下载目录。下载页会显示任务状态、下载进度、已完成文件和失败原因，并支持对失败任务进行重试。应用默认最多同时处理 3 首歌曲的下载任务，以减少对网络和设备资源的占用。

下载完成后，音乐可以在本地音乐页面中继续浏览和播放。实际可下载内容取决于音源、账号权限、接口状态及相关服务的使用限制。

### 音质与播放设置

设置页面提供网易云音乐音质选择，以及与播放和下载相关的选项。用户可以根据网络环境、设备存储空间和个人偏好选择适合的音质。部分高音质或特殊音源可能需要对应账号权限，应用不会绕过第三方服务的权限限制。

### 主题与界面体验

轻音采用简洁的 Material 风格界面，围绕首页、搜索、本地音乐、下载、歌单和“我的”等常用入口组织功能。界面支持沉浸式顶部区域、清晰的播放状态提示和适合单手操作的按钮布局，尽量减少从浏览到播放之间的操作步骤。

“我的”页面集中提供账号、歌单导入、设置和赞赏支持等功能，不将不常用的选项放在主播放路径中。

## 使用方式

安装应用后，轻音可以先作为本地播放器使用。首次打开时，授予访问音乐文件所需的系统权限，然后扫描设备中的音乐；如果音乐存放在特定目录，也可以在本地音乐页面手动添加目录。

需要使用在线功能时，可以在搜索页面输入关键词并选择结果播放。需要同步网易云歌单时，在“我的”页面完成网易云音乐登录；也可以直接导入可访问的 QQ 音乐或网易云音乐歌单信息。下载任务则可在曲目菜单或播放相关操作中加入，之后在“下载”页面查看进度。

## 隐私与第三方服务说明

轻音不在应用内投放广告，也不会因为本地音乐播放而要求用户登录第三方账号。只有在用户主动使用在线搜索、歌单同步、在线歌词、在线播放或下载等功能时，应用才会访问相应的网络服务。

网易云音乐、QQ 音乐及其他音源的内容、账号权限、接口稳定性和可访问范围由相关服务提供方决定。轻音不承诺第三方服务始终可用，也不提供对付费内容、地区限制或账号权限的绕过功能。请用户遵守所在地区法律法规、版权要求以及相关平台的服务条款。

## 许可证边界

轻音的原生 Android 播放体验基于 AndroidX、Jetpack Compose、Media3 和 Android 系统能力实现。项目没有复制其他音乐播放器项目的源代码；对其他项目的研究仅用于功能和交互层面的参考。
