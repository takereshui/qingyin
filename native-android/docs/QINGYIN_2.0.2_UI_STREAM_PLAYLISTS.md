# 轻音 2.0.2 界面、在线播放与歌单修复说明

## 本次修复

本版本将顶部栏改为沉浸式透明布局：应用内容只为系统状态栏保留必要安全区，不再使用占据额外高度的实色标题栏。底部导航增加独立的“搜索”入口，网易云在线搜索不再与首页每日推荐和本地歌曲混排。

完整播放器的进度区域改为细线进度条，移除了滑块拇指与不需要的竖线视觉元素，同时保留当前时间和总时长。系统播放器仍保留程序化定位能力，界面不会在连续播放时出现额外的拖动标记。

网易云在线 URL 解析增加了同一歌曲从当前音质到超清、较高、标准档的逐级回退。返回的明文 CDN 地址会被升级为 HTTPS，以避免 Android 的清晰流量限制阻止播放。如果 NCMC 无法返回任何地址，则在用户已配置 ChKSz API Key 时尝试通过 ChKSz 主/备用线路解析；最终失败时，搜索页和完整播放器会显示 Media3 的明确错误代码。

## 我的歌单

网易云二维码登录成功后，应用立即保存 Cookie、昵称和用户 ID，并触发“我的歌单”同步。歌单列表使用六小时本地缓存；歌单详情使用十二小时缓存。进入“我的”页时会优先展示缓存，右上角刷新按钮可强制拉取最新列表。点击歌单可查看曲目、刷新详情并播放其中歌曲。

> 需要注意的是：我的歌单依赖二维码登录服务端实际返回账户资料中的 `userId`。若登录成功但没有返回用户资料，应用会保留登录状态，并在“我的歌单”区域显示具体提示而不是伪造空歌单。

## 真机验收

覆盖安装后，请首先观察首页和搜索页顶部仅保留状态栏高度的透明安全区。随后打开“搜索”页播放一首可用在线歌曲；若失败，记录页面显示的错误代码并检查 NCMC/ChKSz 线路设置。

请重新进行网易云二维码登录，确认登录成功后“我的”页自动出现歌单状态与列表。点击刷新应主动更新列表；点击任意歌单后应展示歌曲详情。
