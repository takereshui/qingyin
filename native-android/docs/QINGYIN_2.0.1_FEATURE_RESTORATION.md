# 轻音 2.0.1 功能恢复说明

## 本次恢复内容

本版本将用户反馈的旧版核心入口与体验补回 Kotlin 原生主线，同时移除了首页、我的页面和下载页面中的重构、WebView、迁移或技术实现说明。应用内仅保留面向普通使用者的音乐文案。

| 功能 | 恢复或修复方式 |
|---|---|
| 完整统一音质 | 设置中提供标准 128K、较高 192K、超清 320K、无损 FLAC、高解析 Hi-Res、极高 JY Master。网易云播放地址解析与下载读取同一档位。 |
| 封面 | 曲目列表、迷你播放器和全屏播放器使用实际专辑封面；Coil 使用独立 `covers-v2` 磁盘缓存，缓存容量为 120 MB，并对缓存响应保持稳定。网易云封面请求继续使用 300px 级别缩放 URL。 |
| 歌词 | 新增 90 天 LRC 磁盘缓存；本地音乐会按标题、歌手及时长评分匹配网易云歌曲，达到 66 分后获取歌词；无结果会记录 7 天缺失标记，避免反复无效请求。 |
| 每日推荐 | 首页恢复“每日推荐”区。登录后从网易云推荐接口读取，使用 10 分钟磁盘缓存并支持手动刷新。 |
| 赞赏 | “我的”页面恢复“赞赏支持”，在应用内显示本地微信、支付宝二维码，不跳转网页。 |
| 私有和备用线路 | 设置中可编辑 NCMC 主地址、备用地址与手动备用开关；ChKSz 主地址、备用域名开关和 API Key 也被保留。 |
| 开发说明 | 应用中已移除“原生重构”“WebView”“迁移”等开发描述。 |

## 真机验证

请覆盖安装后先打开“我的 → 播放、下载与线路设置”，核对所需音质和私有 NCMC 地址；在首页确认每日推荐加载，再搜索一首带封面的歌曲，检查列表、迷你播放器和完整播放器中的封面。随后播放本地曲目并打开完整播放器，等待歌词匹配；相同曲目再次播放时应优先命中歌词缓存。

最后在“我的 → 赞赏支持”确认微信和支付宝二维码均可在应用内显示。若每日推荐或歌词无法加载，请先确认网易云登录状态、NCMC 主/备用地址和网络可达性，再提供页面显示的错误文字。
