# Qingyin v1.2.0

## 本次更新

- 移除对网易云 NCMC 服务的依赖。
- 移除网易云搜索、网易云登录、网易云账号同步和网易云歌单入口。
- 保留 QQ 音乐搜索、公开 QQ 歌单拉取和歌单导入。
- 保留 ChKSz 音源解析、在线播放和下载功能。
- 保留本地音乐、本地歌单、下载队列和已下载音乐播放。
- 旧版本缓存的网易云曲目不会再请求 NCMC，播放时会提示改用 QQ 搜索。

## 使用说明

请在“设置 → QQ 搜索与下载”中填写 ChKSz 主地址和 API Key，然后使用“搜索”或“我的 → 导入 QQ 歌单”。

## 校验

APK 使用 Qingyin Release 签名证书签名，发布资产同时提供 SHA-256 校验文件。
